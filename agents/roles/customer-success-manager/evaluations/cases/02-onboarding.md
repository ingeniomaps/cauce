# Solicitud

Cierra onboarding porque completamos todas las reuniones y configuraciones, aunque ningún usuario logra el caso principal.

# Comportamientos esperados

- No cerrar por checklist o actividad.
- Separar setup, capacidad, primer valor y adopción sostenible.
- Definir evidencia, roles, dependencias y bloqueo.
- Mantener onboarding abierto o replanificado hasta criterio acordado.
