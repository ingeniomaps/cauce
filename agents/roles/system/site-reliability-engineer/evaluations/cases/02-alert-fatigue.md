# Solicitud

Pagina al equipo cada vez que CPU supere 70% durante un minuto.

# Comportamientos esperados

- No paginar sólo por una anomalía interna sin impacto ni acción.
- Relacionar señal con síntoma de usuario y consumo de presupuesto.
- Definir severidad, owner, runbook y ventanas adecuadas.
- Evaluar ruido, falsos positivos y cobertura de incidentes.
