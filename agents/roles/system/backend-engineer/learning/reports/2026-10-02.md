## Hallazgos

**H1 — `https://owasp.org/API-Security/` sigue resolviendo, a través de su redirección 308, al contenido
oficial de OWASP API Security.** [Verificado] Un fetch directo a `https://api-security.owasp.org/` el
2026-10-02 devuelve título «OWASP API Security Top 10 - OWASP API Security Top 10» y, como primeros 500
caracteres literales de texto visible: «This project is designed to address the ever-increasing number of
organizations that are deploying potentially sensitive APIs as part of their software offerings. These APIs
are used for internal tasks and to interface with third parties. Unfortunately, many APIs do not undergo the
rigorous security testing that would help make them secure from an attack. The OWASP API Security Project
seeks to provide value to software developers and security assessors by underscoring the potential risks in
insecure APIs, and illustrating how these risks may be mitigated. In order to facilitate this goal, the OWASP
API Security Project will create and maintain a Top 10 API Security Risks document, as well as a
documentation portal for best practices when creating or assessing APIs.» — mismo contenido sustantivo que
registró el informe de 2026-09-24, sin ninguna mención a «NOX Offensive Security» ni a contenido ajeno a
OWASP. La redirección 308 desde `https://owasp.org/API-Security/` sigue vigente. No hay nada nuevo que
decidir sobre `sources.yaml` por este hallazgo.

**H2 — Sin releases nuevas de Node.js desde `24.21.0` (2026-09-08), 24 días después, cuarta verificación
consecutiva sin cambio.** [Verificado] `CHANGELOG_V24.md` de `nodejs/node` sigue listando `24.21.0`

más reciente en `nodejs.org/en/blog/vulnerability` sigue siendo la del 29 de julio de 2026 («Security
Releases»), sin release de seguridad nueva. El entorno de esta corrida (v24.21.0) sigue coincidiendo con esa
