## Hallazgos

- **H1.** Node.js 24.x LTS ("Krypton") avanzó de `v24.20.0` a `v24.21.0`, publicada el 2026-09-08 —un día
  después del corte del informe anterior (2026-09-07) y seis días antes de esta corrida—. El changelog de
  esa versión no trae ningún bump de npm (0 líneas con "npm" en `CHANGELOG_V24.md` para esa sección), así
  que la versión de npm empaquetada sigue siendo la misma que reportó el informe anterior (`11.19.0`). Sí
  trae `deps: update OpenSSL to 3.5.8` (#65542), `deps: update corepack to 0.36.0` (#65653) y certificados
  raíz actualizados a NSS 3.126. El listado de releases de seguridad de nodejs.org no incluye ninguna
  entrada de septiembre de 2026, así que esta es una release LTS de rutina, no una release de seguridad
  señalada como tal. Registro: **Verificado** (API de releases de `nodejs/node` y `CHANGELOG_V24.md` en el
  tag `v24.21.0`, ambos consultados 2026-09-14). Impacto: bajo — los ocho `actions/setup-node` de este
  repositorio fijan `node-version: '24'` (flotante) o `matrix.node` en `ci.yml`, así que no hay un pin
  exacto que actualizar; queda como dato para el próximo ciclo.
- **H2.** GitHub publicó un `cache-mode` nuevo para el caché de Actions el 2026-09-10 —posterior al corte
  del informe anterior—: una configuración de nivel workflow o job con cuatro valores (`read`, `write`,
  `write-only`, `none`), con default `read` para eventos de baja confianza como `pull_request_target` y
  `write` para eventos de confianza como `push`; la aplica el servicio de caché y se propaga a través de
  reusable workflows. Registro: **Documentado** (changelog oficial de GitHub, publicado 2026-09-10 —
  distinto del aviso "Early September 2026 updates" del 2026-09-03 que ya cubrió el informe de
  2026-09-07). Impacto: nulo en este ciclo —
  ningún workflow de este repositorio dispara con `pull_request_target` (verificado por búsqueda sobre
  `.github/workflows/*.yml`, único resultado es un comentario que lo menciona sin usarlo,
  `sign-proposal.yml:50`), y los ocho `actions/setup-node` de este repositorio ya declaran
  `package-manager-cache: false` (`ci.yml:49`; `agent-learning.yml:82,217,806,910`; `open-pr.yml:46`;
  `release-pr.yml:52`; `release.yml:36`), así que no hay caché de npm activo al que aplicarle un modo.
- **H3 (confirmación, sin cambio).** Los cuatro pines por SHA de `actions/checkout`, `actions/setup-node`,
  `actions/upload-artifact` y `actions/download-artifact` siguen siendo, esta semana también, el último
