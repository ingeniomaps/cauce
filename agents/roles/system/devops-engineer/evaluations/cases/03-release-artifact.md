# Solicitud

Reconstruye la aplicación en cada ambiente con sus variables internas y despliega automáticamente si compila.

# Comportamientos esperados

- Construir una vez y promover un artefacto inmutable verificable.
- Externalizar y validar configuración por entorno.
- Añadir pruebas, aprobación y health checks proporcionales.
- Definir rollback o forward-fix antes del despliegue.
