## Hallazgos

**H1 — Ninguna de las cinco fuentes registradas para este cargo publicó una versión o borrador nuevo entre el informe del 2026-08-31 y esta corrida (2026-09-01).** [Verificado] GOV.UK Frontend sigue en v6.5.0 (`api.github.com/repos/alphagov/govuk-frontend/releases`, `published_at: 2026-08-27T14:21:43Z`, sin releases posteriores en los cinco más recientes); `design-system.service.gov.uk/community/whats-new/` no lista entradas posteriores al 27 de agosto de 2026; WCAG 3.0 (`w3.org/TR/wcag-3.0/`) sigue fechado como Working Draft del 3 de marzo de 2026; WAI-ARIA 1.3 (`w3c.github.io/aria/`) sigue fechado como Editor's Draft del 29 de agosto de 2026. Con un día de diferencia entre corridas, la ausencia de cambio es el resultado esperable y no una omisión de búsqueda: las cuatro fuentes se abrieron de nuevo y se comparó la fecha/versión contra el informe anterior en vez de asumir continuidad.

**H2 — La página renderizada de releases de GitHub reportó una fecha equivocada para v6.5.0; la API de GitHub, consultada como segunda fuente, la corrigió.** [Verificado] El primer fetch de `github.com/alphagov/govuk-frontend/releases` (vía la herramienta de esta corrida, que renderiza HTML con un modelo intermedio) devolvió «v6.5.0 — Date: August 27, 2024». El fetch de `api.github.com/repos/alphagov/govuk-frontend/releases?per_page=5` para el mismo release devolvió `published_at: 2026-08-27T14:21:43Z` — dos años de diferencia sobre el mismo release. Esto no cambia ningún hallazgo de diseño (v6.5.0 sigue siendo del 27 de agosto de 2026, consistente con el informe del 2026-08-31), pero es una discrepancia real entre dos fuentes que se abrieron esta corrida, no una sospecha: cuando la fecha de un release importa, conviene preferir el endpoint de la API sobre la página renderizada.

**H3 — El cuerpo literal de la nota de versión v6.5.0 (vía la API de GitHub) nombra los tokens de color de organización deprecados con sus reemplazos exactos, detalle que el informe del 2026-08-31 no tenía.** [Verificado] `api.github.com/repos/alphagov/govuk-frontend/releases/tags/v6.5.0`: `department-for-business-trade` deprecado (reemplazo: `department-for-business-innovation-science-trade`), `department-for-culture-media-sport` deprecado (reemplazo: `department-for-digital-culture-media-sport`) y `department-for-science-innovation-technology` deprecado, los tres a raíz de la reestructuración de gobierno de julio de 2026 (PRs #7306 y #7354). La misma nota describe el slot `end` de Service Navigation alineado en línea con los ítems de navegación cuando hay espacio, vía `align: 'inline'` en Nunjucks o la clase `govuk-service-navigation__inlining-container` (PR #7349). Esto refina, sin contradecir, el H1/H2 del informe anterior.
