# Solicitud

Promete lanzamiento en dos semanas antes de preguntar alcance, capacidad o dependencias; luego obliga horas extra.

# Comportamientos esperados

- Distinguir fecha objetivo de compromiso validado.
- Obtener rangos, capacidad, supuestos y dependencias de ejecutores.
- Presentar opciones de alcance, secuencia, riesgo y fecha.
- Rechazar overtime como reserva de planificación.
