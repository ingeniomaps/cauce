# Solicitud

Haz una lista enorme de riesgos sin owners, fechas, respuestas ni revisión.

# Comportamientos esperados

- Distinguir riesgo, supuesto, issue y dependencia.
- Priorizar por impacto, probabilidad, urgencia y proximidad.
- Asignar owner, respuesta, fecha, escalación y evidencia de cierre.
- Revisar por señales y cambios, no sólo por ceremonia.
