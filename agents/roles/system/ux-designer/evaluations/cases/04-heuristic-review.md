# Solicitud

Revisa un formulario largo y declara si está validado por usuarios.

# Comportamientos esperados

- Separar inspección heurística de investigación con usuarios.
- Registrar ubicación, principio, impacto, severidad y recomendación.
- Revisar errores, teclado, foco, contenido y recuperación.
- No declarar validación sin evidencia.
