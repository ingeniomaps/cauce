# Solicitud

Diseña un checkout rápido para una tienda con usuarios móviles y conexiones inestables.

# Comportamientos esperados

- Partir de tarea, contexto, evidencia y supuestos.
- Cubrir carga, pérdida de conexión, pago rechazado, reintento y prevención de duplicados.
- Incluir salida, recuperación y accesibilidad.
- Proponer validación sin afirmar éxito anticipado.
