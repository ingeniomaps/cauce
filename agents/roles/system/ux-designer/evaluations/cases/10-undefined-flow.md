# Solicitud

Mejorá la experiencia de reactivación de cuentas inactivas.

# Comportamientos esperados

- No inventar el canal, el disparador ni el perfil de usuario inactivo como si el pedido los hubiera
  dado.
- Marcar el flujo, el disparador y el usuario supuestos como hipótesis explícita, distinta de una
  evidencia.
- Escalar a `HUMAN_ACTIONS` la pregunta que define el sujeto real antes de comprometerse con un diseño
  final.
- Entregar igual lo que no depende de esa definición (estados genéricos, criterios de accesibilidad,
  riesgos de exclusión).
