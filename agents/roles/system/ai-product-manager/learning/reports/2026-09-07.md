## Hallazgos

**H1 — Anthropic lanzó Claude Fable 5.1 (`claude-fable-5-1`) y Claude Mythos 5.1 (`claude-mythos-5-1`) el
2026-09-01, sucesores de Fable 5 para trabajo agéntico de largo plazo.** [Verificado] Entrada del
2026-09-01 en `platform.claude.com/docs/en/release-notes/overview`, leída el 2026-09-07: «We've launched
Claude Fable 5.1 (`claude-fable-5-1`)... alongside Claude Mythos 5.1 (`claude-mythos-5-1`) for Project
Glasswing participants.» Ambos con ventana de 1M tokens por defecto, 128k tokens de salida máxima y
adaptive thinking siempre activo, al mismo precio que Fable 5 ($10 / $50 por MTok). Corroborado de forma
independiente por cobertura de prensa (Thurrott, SiliconANGLE, MacRumors, Silicon Republic), búsqueda web
del 2026-09-07: Mythos 5.1 es el mismo modelo que Fable 5.1 con salvaguardas adicionales, disponible sólo
por los programas de acceso confiable de Anthropic para ciberseguridad y ciencias de la vida.

**H2 — El 2026-09-03 Anthropic lanzó `ant apply` (CLI v1.30.0): gestión de agentes, environments, skills,
memory stores y deployments como código, con un lockfile (`claude-lock.json`) que evita crear recursos
duplicados en corridas siguientes.** [Verificado] Entrada del 2026-09-03 en la misma página de release
notes, leída el 2026-09-07. Corroborado de forma independiente por la documentación propia
(`platform.claude.com/docs/en/cli-sdks-libraries/cli/apply`) y por cobertura de terceros (AlphaSignal,
Qiita), búsqueda web del 2026-09-07: si alguien edita el recurso desde la Consola en lugar del archivo, la
siguiente corrida de `ant apply` rechaza el cambio.

**H3 — En Claude Fable 5.1 y Mythos 5.1, `tool_choice` de tipo `any` o `tool` ya no está soportado y
devuelve error 400; para forzar un tool call específico hay que usar strict tool use o structured
outputs.** [Verificado] Entrada del 2026-09-01 en la misma página de release notes, leída el 2026-09-07.
La misma entrada documenta que los thinking blocks de estos dos modelos sólo se preservan para el modelo
que los produjo o uno más nuevo, y que para cuentas nuevas creadas desde el 2026-08-31 la API devuelve 400
si se reenvía un thinking block después de que cambió el `system` prompt, las `tools` o un mensaje
anterior.

**H4 — Los cache reads en Claude Fable 5.1 y Mythos 5.1 cuestan $0.25 por MTok (0.025x el precio base de
entrada), contra 0.1x en el resto de los modelos de Anthropic; los cache writes no cambian.** [Verificado]
Entrada del 2026-09-01 en la misma página de release notes, leída el 2026-09-07.

**H5 — Claude Fable 5.1 y Mythos 5.1 exigen retención de datos de 30 días y no están disponibles bajo
zero data retention salvo autorización expresa de Anthropic, igual que Fable 5.** [Verificado] Entrada del
2026-09-01 en la misma página de release notes, leída el 2026-09-07.

**H6 — OpenAI lanzó GPT-6 Astra el 2026-09-03, descrito como su modelo más capaz; según cobertura de su
propia ficha de seguridad, alcanza el nivel «Critical» de capacidad cibernética del Preparedness
Framework y activó monitoreo de desalineamiento (misalignment monitoring) sobre inferencia que usa
herramientas en despliegues externos.** [Verificado — el lanzamiento y las notas de migración] Entrada del
2026-09-03 en `developers.openai.com/api/docs/changelog`, leída el 2026-09-07: el modelo no soporta nivel
de esfuerzo de razonamiento `none`, valores manuales de `temperature`/`top_p` ni logprobs, y el tool
calling requiere la Responses API. [Documentado, no verificado de forma directa] El nivel «Critical» de
capacidad cibernética y el monitoreo de desalineamiento salen de cobertura de terceros (VentureBeat, NBC
News, dev.to, chatgptaihub.com) sobre `openai.com/index/safety-overview-gpt-6-astra/`, búsqueda web del

## Posibles prácticas obsoletas

- Un contrato de sistema que fije `tool_choice: "any"` o `tool_choice: "tool"` contra Claude Fable 5.1 o
  Mythos 5.1 recibe 400; la alternativa documentada es strict tool use o structured outputs (H3).
- Un contrato que asuma zero data retention disponible por defecto sobre Fable 5.1/Mythos 5.1 está
  equivocado salvo autorización expresa de Anthropic: el default es retención de 30 días (H5).
- Un threat/failure taxonomy (paso 6 del flujo de este cargo) construido sobre GPT-6 Astra que no
  contemple capacidad cibernética elevada ni monitoreo de desalineamiento queda desactualizado apenas se
  corrobore H6 contra la fuente primaria de OpenAI.
- El enlace de `operating-model.md:32` señalado como H7 el 2026-08-31 sigue sin corregir un mes después de
  registrado (H8): no es una práctica nueva, es la misma que ya se había anotado y que la propuesta de
  septiembre archivó sin decidir.

corroboración independiente—. Quedan para que la propuesta mensual decida:
