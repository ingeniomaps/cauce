## Hallazgos

**H1 — El 2026-09-22, Anthropic lanzó Claude Opus 5.5 (`claude-opus-5-5`): 1M tokens de contexto por
defecto, 128k tokens de salida máxima, adaptive thinking siempre activo, a $4/$20 USD por MTok (Opus 5
cuesta $5/$25).** [Verificado] Entrada del 2026-09-22 en `platform.claude.com/docs/en/release-notes/overview`,
leída el 2026-09-24: «We've launched Claude Opus 5.5 (`claude-opus-5-5`), a model for long-running
agentic coding and knowledge work. It has a 1M token context window by default, 128k max output tokens,
and always-on adaptive thinking [...] at $4 / $20 USD per MTok (Claude Opus 5 is $5 / $25).» Disponible en
la Claude API, Amazon Bedrock, Claude Platform on AWS, Google Cloud y Microsoft Foundry. Corroborado de
forma independiente por búsqueda web del 2026-09-24 (siliconangle.com, bnnbloomberg.ca, 9to5mac.com): 40%
de reducción de costo típico frente a Opus 5, más de 30% de aumento de velocidad de salida, y Anthropic
señaló que Sonnet 5.5 y Haiku 5.5 llegarían en semanas.

**H2 — El mismo lanzamiento rompe compatibilidad hacia atrás en tres puntos: en Opus 5.5 no se puede
desactivar el thinking (`thinking: {"type": "disabled"}` y la variante `"enabled"` devuelven 400; se
controla la profundidad con el parámetro `effort`), `tool_choice` de tipo `any` o `tool` también devuelve
400 (igual que en Claude Fable 5.1; usar `auto` con strict tool use), y el computer use en la Claude API y
Google Cloud exige el toolset `computer_toolset_20260801` — la tool anterior `computer_20251124` devuelve
400 ahí, aunque sigue funcionando en Amazon Bedrock.** [Verificado] Misma entrada del 2026-09-22, leída el
2026-09-24, con remisión a la guía de migración de Opus 5.5.

**H3 — El mismo día, Fast mode (research preview) quedó disponible para Claude Opus 5.5 en la Claude
API.** [Verificado] Misma entrada del 2026-09-22, leída el 2026-09-24.

**H4 — El mismo día, la Claude API sumó en beta (`inline-tools-2026-09-15`) la posibilidad de definir
tools dentro de un system message a mitad de conversación: un bloque `tool_addition` puede llevar la
definición completa de una tool, así se puede agregar una, cambiar su schema o mover una server tool a una
versión nueva sin editar el arreglo `tools` inicial ni invalidar el prompt cache. Combinado con el header
beta del conector MCP (`mcp-client-2026-09-15`), la definición puede ser un toolset de MCP, y la respuesta
registra en un bloque `mcp_tool_listing` la lista de tools que el servidor devolvió, para fijarla si se la
reenvía.** [Verificado] Misma entrada del 2026-09-22, leída el 2026-09-24.

**H5 — El 2026-09-23, Cache diagnostics salió de beta en la Claude API: ya no requiere el header

en la respuesta, `null` cuando el pedido no mandó el objeto `diagnostics`.** [Verificado] Entrada del
2026-09-23 en la misma página, leída el 2026-09-24.

## Posibles prácticas obsoletas

- Un cálculo de unit economics o un readiness check (paso 7 del flujo) que use el precio de Opus 5 ($5/$25)
  como referencia de costo del modelo Anthropic de mayor capacidad queda desactualizado: Opus 5.5 lo
  reemplaza a $4/$20 con más contexto por defecto y más output máximo (H1).
- Un system contract que fija `thinking: {"type": "disabled"}` o `tool_choice: "any"`/`"tool"`, o que pina
  la tool `computer_20251124`, se rompe con un 400 al migrar a Opus 5.5 en la Claude API o Google Cloud —no
  en Amazon Bedrock, donde `computer_20251124` sigue andando— y necesita el parámetro `effort`, `tool_choice:
  "auto"` con strict tool use, y `computer_toolset_20260801` respectivamente (H2).
- Un system contract (paso 5 del flujo) que gestione el catálogo de tools de forma estática, reenviando el
  arreglo `tools` completo para agregar o versionar una, pierde la alternativa en beta de declarar la
  adición dentro de un system message a mitad de conversación sin invalidar el prompt cache (H4).
- Un cálculo de unit economics que asuma que ningún refusal antes de output se factura en las categorías
  `bio`, `frontier_llm` o `reasoning_extraction` queda desactualizado desde el 2026-09-24 (H6).
- Un ejercicio de comparación de proveedores (paso 6 del flujo) que use GPT-5.6 Sol/Luna como el tier
  económico de OpenAI queda desactualizado: GPT-6 Sol/Luna los reemplaza a la mitad de precio (H7).
