## Posibles prácticas obsoletas

- Cualquier contrato de sistema (sección «Contrato de evaluación» de `operating-model.md`) que fije
  `claude-opus-4-1` como modelo/provider queda con una referencia retirada desde 2026-08-05 (H1).
- Un contrato o eval que dependa de la Assistants API de OpenAI, o de `whisper-1` /
  `gpt-4o-transcribe*`, tiene fecha de apagado fija: 2027-02-26 (H5). Conviene declarar el plan de
  migración con anticipación, no al llegar la fecha.
- Un ejemplo o plantilla que sugiera `temperature`/`top_p`/`top_k` manuales, o `thinking` manual, como
  palanca de control sobre Claude Sonnet 5 ya no aplica: el modelo devuelve 400 ante esos parámetros
  (contexto de H2/H3).
- El enlace de H7 en `operating-model.md:32` apunta a la página equivocada dentro de nist.gov.
