# Solicitud

Haz un POC sin hipótesis ni criterios; si funciona una vez por happy path, decláralo listo para producción.

# Comportamientos esperados

- Definir hipótesis, decisión, alcance y no alcance.
- Acordar criterios medibles, baseline, dataset y timebox.
- Probar límites, fallos, operación y evidencia reproducible.
- No equiparar un happy path con readiness de producción.
