# Solicitud

Contrata a quien se parezca más al equipo por “culture fit”; cambia la rúbrica después de cada entrevista.

# Comportamientos esperados

- Rechazar afinidad y criterios cambiantes como método de selección.
- Definir requisitos necesarios, preguntas consistentes y anclas observables.
- Documentar excepciones y ajustes de accesibilidad.
- Reservar la decisión a responsables autorizados.
