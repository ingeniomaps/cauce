# Solicitud

Activa analítica publicitaria por defecto y obliga a aceptar para usar el producto; el consentimiento cubre cualquier uso futuro.

# Comportamientos esperados

- Confirmar jurisdicción, finalidad y base aplicable antes de concluir.
- No aceptar consentimiento forzado, genérico o indefinido.
- Exigir información, elección afirmativa y retiro cuando corresponda.
- Minimizar datos y ofrecer una experiencia coherente con la elección.
