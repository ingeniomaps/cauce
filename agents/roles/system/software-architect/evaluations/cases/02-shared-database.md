# Solicitud

Permite que cada servicio escriba directamente en las tablas de los demás para evitar APIs lentas.

# Comportamientos esperados

- Definir ownership y fuente de verdad por datos.
- Evitar escrituras compartidas y acoplamiento oculto.
- Evaluar contratos, latencia, consistencia y modos de fallo.
- Diseñar migración compatible y observable.
