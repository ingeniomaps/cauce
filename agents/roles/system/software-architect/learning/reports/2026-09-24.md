## Evidencia

**H1** — Verificado. `arc42.org/download/`, fetch 2026-09-24: mismo texto que el 2026-08-31, «Version 9
adds a Chinese (ZH) translation (...) and Hungarian (May 2026) (...). German is currently at 9.1
(December 2025)», sin versión posterior a 9.1. `github.com/arc42/arc42-template/releases` y `/tags`:
«There aren't any releases here», sin tags — igual que el 2026-08-31. `c4model.com`, fetch 2026-09-24:
sin fecha, versión ni changelog visibles; misma estructura de cuatro niveles y tres diagramas de soporte
que ya recoge `sources.yaml`. Para ISO 42010 y SEI ATAM no se pudo repetir el fetch directo esta vez (ver
Preguntas abiertas para ISO), pero la búsqueda web no encontró mención de una edición posterior a
2022 para ISO 42010 ni de un cambio de método para ATAM — tratado como pista, no como verificación.
Confianza: alta en que las cuatro fuentes de `sources.yaml` siguen apuntando a la misma versión vigente
que el 2026-08-31; ese es el resultado que este hallazgo podía refutar y no lo hizo.

**H2** — Verificado. Fetch directo de https://quality.arc42.org/ el 2026-09-24: «191 quality
characteristics (with 37 aliases)», «150 example requirements», «55 solution approaches (with 51
aliases)», «48 standards and regulations across 13 categories». El informe del 2026-08-31 había
registrado 191/149/55/46 en ese mismo orden. La diferencia (149→150 ejemplos, 46→48 normas) es
compatible con mantenimiento activo del recurso y no con un cambio de alcance o estructura. Sigue sin
fecha de versión visible en la página. Confianza: alta en el conteo actual (fetch directo); no hay forma
de saber desde acá si el cambio ocurrió en este período o si las cifras del informe anterior ya estaban
desactualizadas el día que se citaron.

**H3** — Verificado. Fetch directo de https://leanpub.com/visualising-software-architecture el
2026-09-24: «This book is no longer available for sale.» y «This book now retired - a new version will
be published via O'Reilly in July 2026.», con enlace a
https://www.oreilly.com/library/view/the-c4-model/9798341660113/. La página también registra que la
edición Leanpub se actualizó por última vez el 2025-11-19. No se pudo leer directamente la página de
O'Reilly ni la de Blackwell's (ambas HTTP 403, igual que el 2026-08-31), así que el título exacto
(«The C4 Model: Visualizing Software Architecture»), el ISBN y la coautoría con Susanne Kaiser
mencionada en una charla de GOTO 2026 quedan en el registro de lo consultado por búsqueda web, no
verificados directamente. Confianza: alta en que el libro se está republicando en julio de 2026 vía
O'Reilly (fuente primaria, el propio autor); media-baja en cualquier detalle de contenido o coautoría,
porque esa parte no se pudo leer en una página propia del editor o del autor.

Relevancia directa: `sources.yaml` no cita ningún libro para C4 model, sólo `c4model.com`. Esta
republicación no cambia esa fuente —el sitio web sigue siendo la referencia primaria y gratuita— así que
no genera una recomendación de cambio de contrato.

**H4** — Verificado. Fetch directo de
https://www.linuxfoundation.org/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation
el 2026-09-24: comunicado fechado «09 December 2025», que describe la AAIF como estructura de gobierno

primaria verificada de forma independiente por cada uno.
