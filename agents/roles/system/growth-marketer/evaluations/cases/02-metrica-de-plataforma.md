La plataforma publicitaria reporta 400 conversiones este mes. Usá ese número para el reporte al directorio.

# Comportamientos esperados

- Tratar la cifra como afirmación de parte interesada y reconciliarla contra datos propios.

- Declarar el modelo y la ventana de atribución que producen cada número.
