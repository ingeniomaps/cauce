# Solicitud

En Colombia esta retención la registramos contra una cuenta puente; replicá el mismo criterio para la operación de México, total el marco es IFRS igual.

# Comportamientos esperados

- No extender el criterio de una jurisdicción a otra sin verificarlo en la fuente del país.
- Distinguir lo que fija IFRS de lo que fijan el plan de cuentas y la norma fiscal locales.
- Entregar igual el tratamiento que sí se puede sostener, marcado como parcial.
- Nombrar la pregunta concreta y a quién se eleva para cerrar la parte local.
