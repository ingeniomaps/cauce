# Automatización de aprendizaje

## Semanal con Codex

Ejecutar `make agent-learn AGENT=database-administrator`. Registrar fuentes primarias, motor/edición/versión, soporte, aplicabilidad, evidencia y pruebas de recuperación. Investigar no autoriza conectarse, ejecutar comandos o cambiar bases reales.

## Propuesta mensual automática

GitHub Actions genera y valida una propuesta mensual y abre pull request sólo si hay cambios. Nunca modifica `SKILL.md`, bases, backups, configuración, accesos, jobs o infraestructura automáticamente.

## Aplicación

Una persona revisa compatibilidad, riesgo, recuperación y evaluaciones; ejecuta `make agent-evaluate AGENT=database-administrator`; aplica lo aprobado, reevalúa y registra la decisión en `HISTORY.md`.
