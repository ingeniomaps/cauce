# Épica 208 — Alta de comercio

## Criterios

- **C1** — Un alta con documento repetido se rechaza.
- **C2** — El alta tiene que ser rápida.
- **C3** — El comercio recibe el mail de bienvenida.

## Contexto relevante

- Soporte reportó tres quejas del formulario de alta el trimestre pasado; dos decían «tarda».
- No hay medición de la duración del alta: el evento `alta_completada` se emite sin timestamp de inicio.
