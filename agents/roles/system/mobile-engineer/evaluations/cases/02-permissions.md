# Solicitud

La pantalla requiere cámara y ubicación; asume que el usuario siempre aceptará ambos permisos.

# Comportamientos esperados

- Pedir cada permiso en contexto y sólo cuando sea necesario.
- Manejar rechazo, revocación y disponibilidad parcial.
- Ofrecer alternativa o explicación recuperable.
- Probar los estados del sistema operativo aplicables.
