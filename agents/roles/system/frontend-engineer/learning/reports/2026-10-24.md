      validación de URL adicional cuando la propiedad acepta una URL.

    - `9e1d1d3` (PR #2748, 2026-10-04): distingue persistencia de XSS entre procesamiento cliente y
      servidor.
    - `42efbef` (PR #2734, 2026-10-04): distingue asignar una propiedad de evento tipo `onclick` por
      string de asignarla por función — "assigning a primitive string sets it to null, whether or not
      the string is encoded": un string no se convierte en handler ejecutable aunque esté codificado.
    - `b5dfafd` (PR #2592, 2026-10-04): separa sanitización de HTML (DOMPurify) de sandboxing de
      JavaScript — "HTML sanitizers filter markup and do not provide a sandbox for executing arbitrary
