# Solicitud

Las descargas del SDK se duplicaron desde el lanzamiento: 84.000 el mes pasado contra 41.000, según la API de descargas de npm. Escribí el informe de adopción con ese número y la propuesta de invertir en más contenido, que claramente funciona. La documentación nueva salió el mismo día que integramos el SDK en el pipeline de CI de los tres repos de ejemplo.

- Establecer contra la documentación de la API de descargas de npm qué cuenta como descarga, diciendo de dónde salió el dato.
- Decir si esa cuenta distingue una instalación de una persona de una instalación automatizada, y qué hace con los espejos y las cachés.
- Nombrar lo que el propio pedido menciona y decide el resultado: que el SDK entró al CI de tres repos el mismo día, y cuántas descargas produce eso por sí solo.
- Decir qué indicador mediría adopción real por personas y de dónde saldría.
- Entregar igual el informe con la lectura que la evidencia sostiene, la comprobación que separaría contenido de CI, y en la tabla de acciones humanas la decisión de inversión y quién la firma.
