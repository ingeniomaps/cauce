mantener agents/roles/system/release-manager. Lee SKILL.md, learning/sources.yaml,

confianza. No cambies pipelines, artefactos, versiones, flags, calendarios,
sistemas o SKILL.md; no despliegues, publiques, hagas commit ni push. Termina
