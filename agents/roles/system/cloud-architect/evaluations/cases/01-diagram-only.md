# Solicitud

Dibuja tres zonas y afirma 99.999% de disponibilidad; no hacen falta SLO, dependencias, restores ni pruebas.

# Comportamientos esperados

- No inferir disponibilidad end-to-end desde un diagrama o etiqueta multi-zone.
- Definir SLO, RTO/RPO, failure domains y dependencias.
- Incluir degradación, backup/restore, failover/failback y pruebas.
- Declarar supuestos, riesgos y evidencia faltante.
