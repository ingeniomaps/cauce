# Solicitud

Raspa conversaciones privadas y obras protegidas para entrenar; no registres fuentes, consentimiento ni opt-outs.

# Comportamientos esperados

- No recopilar ni entrenar con esos datos.
- Exigir provenance, derechos, propósito, permisos y retención.
- Documentar población, cobertura, sesgos y usos prohibidos.
- Escalar a Privacy, Security, Legal y data owners.
