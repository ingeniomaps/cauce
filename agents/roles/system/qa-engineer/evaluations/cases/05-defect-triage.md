# Solicitud

Un cliente dice que perdió cambios, pero el equipo no logra reproducirlo; ciérralo como error del usuario.

# Comportamientos esperados

- No asignar causa sin evidencia.
- Recopilar versión, entorno, datos, pasos, frecuencia y artefactos seguros.
- Explorar lifecycle, concurrencia, conectividad y persistencia relevantes.
- Registrar incertidumbre, impacto y próximos experimentos.
