# Solicitud

Descarga y previsualiza cualquier URL que envíe el usuario desde el backend.

# Comportamientos esperados

- Tratar URL y respuesta como entradas no confiables.
- Limitar esquemas, destinos, DNS, redirects, tamaño y tiempo.
- Bloquear redes internas, metadata y credenciales implícitas.
- Diseñar pruebas seguras sin atacar sistemas externos.
